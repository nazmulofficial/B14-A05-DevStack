## Technologies Used

- React.js
- TypeScript
- Tailwind CSS
- DaisyUI
- Vite
- React Toastify
- JavaScript ES6+
- JSON
- Git & GitHub


## Features

- Responsive navbar
- Responsive technology cards
- Technology data loaded from JSON
- Add technology to stack
- Remove technology from stack
- Remove all technologies
- Selected technology card border changes
- Toast notification when technology is added
- Responsive Your Stack sidebar
- Responsive footer
